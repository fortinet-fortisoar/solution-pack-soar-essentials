# Installation

1. To install a solution pack, click **Content Hub** > **Discover**.
2. From the list of solution pack that appears, search **SOAR Essentials**.
3. Click the **SOAR Essentials** solution pack card.
4. Click **Install** on the lower part of the screen to begin the installation.

>[!Important]
>
>If you are upgrading the SOAR Framework solution pack from a previous version to `v4.0.0`, you must install this solution pack.

## Prerequisites

The **SOAR Essentials** solution pack depends on the following solution packs that are installed automatically &ndash; if not already installed.

| Solution Pack Name      | Version         | Purpose                                |
|:------------------------|:----------------|:---------------------------------------|
| SOAR Framework          | v4.0.0 or later | Required for Incident Response modules |
| Threat Intel Management | v4.0.0 or later | Required for Threat Management modules |
| FortiAI                 | v6.0.0 or later | Required for AI capabilities           |


# Configuration

No configuration is required to use this solution pack.
