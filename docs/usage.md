# Usage

This solution pack cannot be used independently. However, after the installation of this solution pack, the navigation menu would appear as follows:

| Menu                     | Sub-menu                                                                                                                                       |
|:-------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------|
| Dashboard                | None                                                                                                                                           |
| AI                       | - AI Agents<br />- AI Insights                                                                                                                 |
| Security Operations      | - Alerts<br />- Cases<br />- Tasks<br />- Indicators<br />- Campaigns<br />- Communications<br />- War Room<br />- Workload & Shift Management |
| Threat Intelligence      | - Overview<br />- Search<br />- Hub<br />- MITRE ATT&CK<br />- Hunts                                                                           |
| Vulnerability Management | - Scans<br />- Vulnerabilities<br />- CVEs                                                                                                     |
| Orchestration            | - Playbooks<br />- Connectors<br />- Data Ingestion<br />- Schedules                                                                           |
| Resources                | - Attachments<br />- Email Templates<br />- Key Store<br />- Assets<br />- Identities<br />- Simulations                                       |
| Content Hub              | None                                                                                                                                           |
| Reports                  | None                                                                                                                                           |
| Help                     | - Documentation<br />- User Community                                                                                                          |

## Export Navigation Menu

You can take a backup of your current navigation menu structure using the following steps:

1. Navigate to **Setting** > **Import & Export**

2. Click the **Export** tab.

3. Click **New Template**.

4. Select the box **Administrative Settings** and click **Continue**.

5. Select **System Views** > **Navigation Structure** and click **Continue**.

6. Click **Save and Run Export** to export it.

## Import Navigation Menu

You can take a backup of your current navigation menu structure using the following steps:

1. Navigate to **Setting** > **Import & Export**

2. Click the **Import** tab.

3. Click **Import From File** and upload the exported file.

4. Ensure that **System Views** is selected under *Configurations* of the Import wizard and click **Continue**.

5. Select **System Views** > **Navigation Structure** and click **Continue**.

6. Click **Run Import** to import your custom navigation menu.
